PO-04 Step 0 - shared components the design-lock routes import, in source order
==============================================================================

The design lock is https://www.samanportable.com/product/porta-cabins, which is the
CATEGORY HUB route src/pages/product/[category]/index.tsx. PO-04 is a PRODUCT page,
src/pages/product/[category]/[slug].tsx. Both compose the same production components
and both opt into the same design system; the hub does it through four `category ===`
gates, the product route through the CLUSTER_DESIGN_SLUGS set. No new route file is
authored for this page: /product/portable-office/executive-portable-office resolves
through the existing dynamic product route.
