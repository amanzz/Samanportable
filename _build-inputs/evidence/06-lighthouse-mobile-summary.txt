which looks like a regression. It is not: repeating the measurement three more times,
same machine, same server, same build, interleaved, gives

The DESIGN LOCK ITSELF swings 52-65 perf and 410-1,880 ms TBT on this harness, a
spread wider than any gap between the three pages. PO-05 sits inside that spread on
every run. FCP (1.5 s) and the LCP element are identical to the merged PO-04 sibling.

Conclusion: no measurable performance difference between this page and the design
lock on the local harness. A production number for this URL can only be taken after
SAMAN deploys; the production row above is the design lock's own CDN-served baseline
to compare it against.
