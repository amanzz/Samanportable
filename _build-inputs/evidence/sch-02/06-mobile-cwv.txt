READING

CLS is 0.0000 on this branch, on the design lock and on today's production page.
That is the metric this gate exists for: a template-conformance defect shows up as
layout shift the lock does not have, and there is none.

LCP is 1,140 ms locally against 820 ms for production, which is served from a CDN;
the two are not comparable and the local figure is well inside a good LCP anyway.

TBT: 994 ms on this branch against 806 ms on today's production build of the same
route - same order, same 6 long tasks, and the gap is inside this machine's run to
run spread (the same page measured 978 ms and 818 ms on two earlier passes). The
221 ms reading on prefab-container-homes is not a counter-example: that page is
simply lighter, and it is NOT the Section 4 calculator, which prefab renders in
full SSR exactly as this route does (108 calculator steps on both). No TBT
regression is attributable to this branch.
