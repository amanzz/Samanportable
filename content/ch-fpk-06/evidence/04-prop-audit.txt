CH-FPK-06 Template Conformance Gate - artefact 4
Prop audit: every opt-in this route sets, and why.

No shared component is forked, no new prop is invented and no styling is written.
Everything below is an EXISTING opt-in that already ships on at least one sibling.

A. ROUTE PROPS - src/pages/product/[category]/[slug].tsx
-----------------------------------------------------------------------------
  CLUSTER_DESIGN_SLUGS += 'flat-pack-container-homes'
      Turns on the porta-cabins design lock for this route: usePremiumSizeTabs
      (saman-size-chips / saman-size-chip in the buy box, saman-size-tabs /
      saman-size-tab in the Section 3 explorer), showSectionDividers, and the
      eleven-block order. Same membership CH-PFB-04 added for its own slug.

  explorerPanelHeadingAsH2  = FALSE for this slug
      Build prompt v1 section 6: "Section 3 size headings render as H3, which is
      what the design lock does." The signed pack names the field `h3`. Scoped OFF
      exactly as PO-05, PO-06, PO-07, PO-08 and CH-PFB-04 scope it. Both branches
      share an identical class string, so only the heading LEVEL differs.

  sizeEyebrowText = 'Choose your size - six factory-built options'
      The pack carries no size-selector label. The shared premium default is
      'Choose your size — six factory-built options' with a U+2014, which this
      page's gate bans. This is the already-deployed hyphen literal that
      construction-site-cabin, prefab-container-homes and eight other slugs
      render; no new copy is authored.

  relatedTiles branch      (Explore the Range reads variantData.relatedTiles)
  ymalTiles block          (You may also like reads variantData.ymalTiles)
      The same JSON-driven branch bess-container, CO-06, CO-07 and
      prefab-container-homes already use. The shared YMAL constants are untouched.

  reviews = []  /  averageRating = undefined  /  ratingCount = 0
      No verified reviews exist for this product, so none is published and no
      rating schema is emitted. Same list fourteen other slugs are already in.

  reviewsEmptyStateText = copy pack tabs.reviews.empty_state
      Renders the pack's "No verified reviews yet." instead of the shared default
      "No reviews yet. Be the first to review this product.", which would be a
      claim about this product that the pack does not make.

  fullMobileLabels         NOT SET (default false)  <-- deliberate
      fullMobileLabels={true} makes the small-screen tab label equal to the
      desktop one, which is the "DescriptionDescription" defect build prompt
      section 8 names. Left at its default so the strip reads
      Description/Info, Specifications/Specs, Shipping/Ship, Reviews.
      Confirmed on the served page: <span class="sm:hidden"> yields
      Info / Specs / Ship.

    infoImages         SET (six), see below - listed here only to record that the

C. DIFFERENCES FROM THE NEAREST SIBLING (prefab-container-homes, PR #200)
-----------------------------------------------------------------------------
  labelActiveThumbnailAlt   flat-pack true / prefab absent
      Gate artefact 5 on this page bans an empty alt; prefab's gate did not.
  materialLabel             flat-pack absent / prefab set
      prefab keeps the standard cell set; this pack replaces it (see above).
  priceCaption              flat-pack absent / prefab set
      prefab's pack supplies one; this pack does not.
  trustWarranty             flat-pack absent / prefab set
      this pack bans a warranty term outside the Description tab.
  trustStripText            'GST registered' / 'GST registered · Pan-India delivery'
      the shorter already-deployed literal; this pack makes no delivery-coverage
      claim in the buy box.
  Section 3 image `fit`     flat-pack default (cover) / prefab 'contain'
      Build prompt section 5: this page's board is the 489:374 sheet PADDED
      symmetrically to exact 4:3 on the board ground, so the 4:3 object-cover box
      clips nothing. prefab feeds an unpadded 489:374 sheet and needs contain.
