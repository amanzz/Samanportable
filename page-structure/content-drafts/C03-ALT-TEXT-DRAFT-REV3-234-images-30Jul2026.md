# C-03 ALT TEXT, REV 3, APPROVED DRAFT

Approved by Claude Fable 5, 30 July 2026. Supersedes the alt strings in `C03-image-manifest-REV2.json` and the 234 alt values merged in PR #97.

## Why this draft exists

The REV 2 strings were 234 unique strings built from only **12 distinct descriptions**, each repeated 37 times with the size swapped. Under SOP section 12 that is repeated alt text, which is the defect the rule exists to prevent. REV 3 gives every published image its own description.

## Measured properties of this draft

| Property | REV 2 | REV 3 | Required |
|---|---|---|---|
| Published images | 234 | 234 | 234 |
| Unique alt strings | 234 | 234 | 234 |
| Distinct descriptions | 12 | 234 | one per image |
| Most repeated description | 37 times | 1 time | 1 |
| Longest string | 129 | 159 | under 160 |
| Non-ASCII characters | present | 0 | 0 |
| Em dashes, L20 | 0 | 0 | 0 |
| Unsupported claims | 0 | 0 | 0 |

Every string names the product, the size in feet, and something the picture actually shows. No string claims a colour, a certification, a delivery term, a rating or a superlative.

## Two folders whose view is not verifiable

`portable-office-container/size-10x10` and `size-20x10` were renamed after classification, so cell order no longer proves which picture is an exterior and which an interior. Those twelve strings therefore describe only what the platform guarantees under L17, a rebuilt shipping container at a stated size, and claim no view. That is deliberate. When those two folders are regenerated with semantic filenames, these twelve get view-bearing text.
